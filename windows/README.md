# Общий буфер — программа для Windows (ПК и ноутбук)

Значок в трее (стрелочка `^` справа внизу, рядом с Wi-Fi). Клик — всплывающая панель
со всем, что лежит в общем буфере на роутере.

- **Получить:** новые записи сами появляются в панели (и приходит уведомление).
  Файлы заранее скачиваются, поэтому их можно **просто перетащить мышкой** на рабочий стол,
  в папку или в письмо. Ссылка — клик «открыть», текст — клик «копировать».
  Двойной клик — главное действие (открыть файл / ссылку, скопировать текст).
- **Отправить:** перетащить файлы на панель, или открыть панель и нажать **Ctrl+V**
  (файлы, скопированные в Проводнике, скриншот или текст), или правый клик по значку →
  «Отправить буфер обмена».
- Правый клик по записи: копировать (файл потом вставляется Ctrl+V в папке), открыть,
  показать в папке, сохранить как…, удалить из общего буфера.
- Клавиши в панели: `Ctrl+V` отправить, `Ctrl+C` копировать, `Del` удалить,
  `Enter` открыть, `Esc` закрыть.

## Установка

1. Положи `SharedClipboard.exe` в постоянную папку, например
   `C:\Users\<ты>\AppData\Local\Programs\SharedClipboard\` (или просто в «Документы»).
2. Запусти. Windows может показать синее окно SmartScreen (программа не подписана):
   «Подробнее» → «Выполнить в любом случае».
3. В настройках: адрес `clip.lan` (или `192.168.8.1:8765`), токен с роутера
   (`uci get clipd.main.token`) и имя устройства — «ПК» / «Ноутбук».
   Можно вставить в поле адреса ссылку `http://…:8765/#token=…` — токен подставится сам.
4. Чтобы значок всегда был виден, а не прятался под стрелочкой: перетащи его мышкой
   из-под `^` на панель задач.

Настройки: `%APPDATA%\SharedClipboard\settings.json`.
Кэш файлов и журнал: `%LOCALAPPDATA%\SharedClipboard\` (`log.txt` — если что-то не так).

## Сборка

Нужен .NET 8 SDK.

```sh
dotnet test tests/SharedClipboard.Core.Tests     # тесты ядра против настоящего clipd (нужен Go)
dotnet publish src/SharedClipboard -c Release -o dist   # dist/SharedClipboard.exe (~65 МБ, всё внутри)
```

Устройство:
- `src/SharedClipboard.Core` — связь с роутером (WebSocket + HTTP), кэш файлов, настройки.
  Без Windows-зависимостей, тестируется на любой ОС.
- `src/SharedClipboard` — WPF: значок в трее, панель, окно настроек, работа с буфером обмена.
- `tools/make_icon.py` — рисует `app.ico` (нужен Pillow).
