# Общий буфер — приложение для телефона (Android, Samsung S24)

## Установка

1. На телефоне откройте ссылку и скачайте APK:
   https://github.com/xxcay/clipboard/releases/download/android-latest/SharedClipboard.apk
2. Откройте скачанный файл. Samsung попросит разрешить установку из браузера /
   «Моих файлов» — разрешите и нажмите «Установить».
   (Play Защита может предупредить о неизвестном приложении — «Всё равно установить».)
3. При первом запуске: адрес роутера `clip.lan` (или `192.168.8.1:8765`), токен
   и имя телефона. Можно вставить ссылку `http://…:8765/#token=…` — токен подставится сам.
4. Разрешите уведомления.
5. В настройках, раздел «Быстрый доступ»:
   - «Виджет на главный экран» — одно нажатие, виджет сам встанет;
   - «Плитка в шторке» — добавит кнопку «Отправить буфер» в быстрые настройки;
   - «Не ограничивать в фоне» — чтобы Samsung не обрывал связь.

Обновление: скачайте APK по той же ссылке и установите поверх — данные сохранятся.

## Как пользоваться

- **С телефона на ПК:** скопируйте что угодно → нажмите «Отправить буфер»
  (виджет, плитка в шторке, кнопка в уведомлении, долгое нажатие на значок приложения)
  или «Вставить из буфера» в приложении.
- **Фото и файлы:** «Поделиться» в Галерее / любом приложении → «Общий буфер».
  Отправляется оригинал, без сжатия. Или кнопки «Фото и видео» / «Файл» в приложении.
- **С ПК на телефон:** приходит уведомление с кнопками «Копировать» / «Открыть» /
  «Сохранить». В приложении: нажатие — открыть / скопировать, долгое нажатие — все действия.

Android разрешает читать буфер обмена только открытому приложению, поэтому отправка
с телефона — всегда по нажатию (виджет, плитка, уведомление), а не автоматически.

## Сборка

APK собирает GitHub Actions (`.github/workflows/android.yml`) и выкладывает в релиз
`android-latest`. Локально: `./gradlew assembleRelease` (нужен Android SDK 35, JDK 17).
Подпись — ключ `app/signing.keystore` из репозитория, чтобы обновления ставились поверх.
